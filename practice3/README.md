# Practice 03: Python Functions, Lambda, OOP and Inheritance

## 📚 Overview
This project contains practical examples demonstrating core Python concepts:

- Python Functions
- Lambda Expressions
- Classes and Objects
- Inheritance

All examples are based on W3Schools tutorials and include comments explaining the code.
